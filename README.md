# Refixes

Server fixes and optional optimizations for Hytale 0.7.7, based on Hyfixes and Hyzen Kernel. On newer 0.7 versions Refixes applies only the early patches whose Hytale code is unchanged and lists the skipped ones at startup. On older versions it applies none. For Hytale 0.8.0-pre.6, use [Refixes 0.8.0-beta.1](https://github.com/IroriPowered/refixes/releases), see [Compatibility](https://wiki.hytalemodding.dev/mod/refixes/installing-refixes#compatibility). Requires [Hyinit](https://github.com/IroriPowered/hyinit/releases/tag/0.3.0) 0.3.0 or newer. Install the single `refixes-X.X.X.jar` in `earlyplugins`.
