# Refixes

Server fixes and optional optimizations for Hytale, based on Hyfixes and Hyzen Kernel. Supports Hytale 0.8.0-pre.6. On newer 0.8 versions Refixes applies only the early patches whose Hytale code is unchanged and lists the skipped ones at startup. On older versions it applies none. Requires [Hyinit](https://github.com/IroriPowered/hyinit/releases/tag/0.3.0) 0.3.0 or newer. Install the single `refixes-X.X.X.jar` in `earlyplugins`.
