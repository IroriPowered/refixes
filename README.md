# Refixes

Server fixes and optional optimizations for Hytale 0.7.7, based on Hyfixes and Hyzen Kernel. Pre-release builds are not supported. Requires [Hyinit](https://github.com/IroriPowered/hyinit/releases/tag/0.3.0) 0.3.0 or newer. Install the single `refixes-X.X.X.jar` in `earlyplugins`.
