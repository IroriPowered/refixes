# Refixes

Server fixes and optional optimizations for Hytale 0.7.7, based on Hyfixes and Hyzen Kernel. For Hytale 0.8.0-pre.5 and later 0.8 versions, use [Refixes 0.7.0-pre.5](https://github.com/IroriPowered/refixes/releases/tag/0.7.0-pre.5). Requires [Hyinit](https://github.com/IroriPowered/hyinit/releases/tag/0.3.0) 0.3.0 or newer. Install the single `refixes-X.X.X.jar` in `earlyplugins`.
