# Refixes

Server fixes and optional optimizations for Hytale, based on Hyfixes and Hyzen Kernel. Supports Hytale 0.8.0-pre.5 and later 0.8 versions. Other versions are not supported. Requires [Hyinit](https://github.com/IroriPowered/hyinit/releases/tag/0.3.0) 0.3.0 or newer. Install the single `refixes-X.X.X.jar` in `earlyplugins`.
